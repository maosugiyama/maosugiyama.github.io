# 教材の自動点検

直したあと、公開する前に走らせてください。

```
node tests/check.js       # 中身の点検（Chrome は要りません）
node tests/contrast.js    # 文字の読みやすさ（Chrome を使います）
```

問題があると終了コードが 1 になります。

## なぜ要るのか

`index.html` は**1万4千行の1ファイル**です。手で直すと、気づかないうちに
別のところが壊れます。実際に起きたのは、たとえば次のようなことでした。

- 一括置換が、あいだにある別の項目まで飲みこんで**絵が6点消えた**
- 閉じタグが**1個余り**、そこから下の表示が崩れた
- CSSのエスケープが二重になり、星印が**「2606」という文字**で表示された
- 問題を途中に足したので番号がずれ、**解説が別の問題に付いた**（5回）
- 背景の色を変えたら、曜日の文字が**コントラスト基準を割った**

どれも見た目には気づきにくく、**すべてこの点検で見つけたもの**です。

## check.js が見ているもの

1. 練習問題の形（選択肢の数、正解の番号、重複、並べ替えの語と正解の一致）
2. **選択肢ごとの解説と問題の対応**（番号のずれ、数の食い違い、空欄）
3. 解説のHTMLタグが閉じているか
4. 答えが問題文に見えていないか
5. 表記のきまり（ё にアクセント記号を重ねない／1音節の語に付けない）
6. 画像が実在するか、`sw.js` のキャッシュ一覧に載っているか
7. 目次の飛び先が実在するか
8. 版の数字（`APP_VERSION`・`sw.js`・`CITATION.cff`）

「気になるところ」は参考情報で、止めはしません。
形態素を示すための断片（`ша́пк-а` の `ша́пк` など）が混じるためです。

## 直したあとの手順

1. `node tests/check.js` と `node tests/contrast.js` を走らせる
2. `sw.js` の `VERSION` を1つ上げる（上げないと古い内容が端末に残ります）
3. commit して push
