# 広告・アイコンの編集用ソース

- ad2.html …… Twitter告知画像（1600×900）のソース。headless Chrome で
  スクリーンショットを撮り、JPEG化して使う:
  chrome --headless=new --window-size=1600,900 --screenshot=ad.png ad2.html
- cover/unit/drill.png …… アプリ実画面の撮影素材（幅500px）
- photo.png（公園のかもたち）/ square.png（赤の広場）/ hats.png（帽子イラスト）
- icon-source.html …… アプリアイコン（つなげ字АБВのねこ）のSVGソース。
  512/192/180で撮影して icon-*.png / apple-touch-icon.png を作る
- icon-source-favicon.html …… ファビコン（耳のあるА）のソース
